# Results Directory

This directory stores intermediate outputs generated by the analysis pipeline.
Large result files (e.g., classification fold metrics CSVs) are excluded from
the repository by .gitignore.

The following subdirectory structure is expected:

- esults/fastspar/microbiota/  — Microbial co-abundance network GraphML files and module eigengenes
- esults/fastspar/proteomics/  — Protein co-expression network outputs
- esults/proteomics_covariate_analysis/  — ANCOVA results per model (Main, Systemic, Statin, Medications)
- esults/microbiota_covariate_analysis/  — ANCOM-BC2 + ALDEx2 results per model
- esults/modeling/classification/  — Nested CV outputs (fold metrics, coefficient stability)
- esults/modeling/ — Mediation analysis results
- esults/psm/  — PSM balance summary
- esults/figures/  — Generated publication figures
- esults/tables/  — Generated supplementary tables

The GraphML files in esults/fastspar/microbiota/ (e.g., microbiome_G_C1.graphml)
are intermediate network results generated by FastSpar — they are not participant-level data.
Whether to include these files in the repository should be decided after confirming
their size and content with the data access policy.
